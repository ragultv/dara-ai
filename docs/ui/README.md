## Ground rules (the short version)

1. The backend is finished and is the source of truth. The UI never computes what fits the GPU, speeds or quality labels; it displays what `/dara/models/{id}/options` says. Never show a number that came from a guess; "not measured" is a valid thing to display.
2. Colors: **purple is primary, white is secondary, black is tertiary.** Only use the semantic tokens (`--color-*`) from `tokens.css`; no hex values in components.
3. The server and the UI together must stay under 300 MB of RAM. The UI budget is about 75 to 115 MB. That is why the stack is Tauri (system WebView), not Electron, and why the app ships no heavy UI libraries.
4. Local only. No telemetry, no external requests except model downloads the user starts (done by the server, not the UI).
5. Do not copy Ollama's look or wording. Dara has its own identity (see the design system).

## Setting up Antigravity

Antigravity reads project guidance from the repo. This repo contains thin adapters that point to this handbook:

- Rule (always on): `.agents/rules/dara-ui.md`
- Skill (loaded for UI work): `.agents/skills/dara-ui/SKILL.md`
- Workflows (slash commands): `.agents/workflows/new-screen.md`, `add-api-call.md`, `ui-review.md`
- `app/AGENTS.md`: guidance when the agent works inside `app/`

Open the repo folder `D:\darap-ai` (not just `app/`) as the workspace so these are found. Then paste the kickoff prompt below into the first conversation.

### Kickoff prompt

```text
You are building the Dara desktop app in the app/ folder of this repo, on branch ui/desktop-app.
Read docs/ui/README.md and every file it links, then docs/ui/07-roadmap-and-tasks.md.
Start with Milestone 0 only: scaffold Tauri 2 + Svelte 5 + Vite + TypeScript + Tailwind v4, import docs/ui/tokens.css,
spawn dara.exe serve as a sidecar with a random API key, and show GET /health on screen.
Follow docs/ui/06-coding-standards.md. When the milestone's acceptance criteria are met, run the checks, commit, and stop for review.
Do not change anything outside app/ and docs/ui/ without asking. Do not edit tokens.css by hand.
```

Work one milestone per conversation; review and commit between milestones.
